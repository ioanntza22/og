## Γεια, καλώς ήρθατε στο Logseq!
- Το Logseq είναι μια πλατφόρμα _με προτεραιότητα στο απόρρητο_, [ανοιχτού κώδικα](https://github.com/logseq/logseq) για διαχείριση _γνώσης_ και συνεργασία.
- Αυτό είναι ένα 3λεπτο εκπαιδευτικό υλικό σχετικά με τη χρήση του Logseq. Ας ξεκινήσουμε!
- Ακολουθούν μερικές συμβουλές που μπορεί να σας φανούν χρήσιμες.
#+BEGIN_TIP
Κάντε κλικ για να επεξεργαστείτε οποιοδήποτε μπλοκ.
Πληκτρολογήστε `Enter` για να δημιουργήσετε νέο μπλοκ.
Πληκτρολογήστε `Shift+Enter` για νέα γραμμή.
Πληκτρολογήστε `/` για να εμφανιστούν όλες οι εντολές.
#+END_TIP
- 1. Ας δημιουργήσουμε μια σελίδα με τίτλο [[Πώς να κρατάτε δοκιμαστικές σημειώσεις;]]. Μπορείτε να κάνετε κλικ πάνω της για να μεταβείτε σε αυτή τη σελίδα, ή `Shift+Κλικ` για να την ανοίξετε στη δεξιά πλαϊνή μπάρα! Τώρα θα πρέπει να βλέπετε τόσο τις _Συνδεδεμένες αναφορές_ όσο και τις _Ασύνδετες αναφορές_.
- 2. Ας αναφέρουμε μερικά μπλοκ στη σελίδα [[Πώς να κρατάτε δοκιμαστικές σημειώσεις;]], μπορείτε να κάνετε `Shift+Κλικ` σε οποιαδήποτε αναφορά μπλοκ για να την ανοίξετε στη δεξιά πλαϊνή μπάρα. Δοκιμάστε να κάνετε
αλλαγές στη δεξιά πλαϊνή μπάρα, τα αναφερόμενα μπλοκ θα αλλάξουν κι αυτά!
    - ((5f713e91-8a3c-4b04-a33a-c39482428e2d)) : Αυτή είναι μια αναφορά μπλοκ.
    - ((5f713ea8-8cba-403d-ac00-9964b1ec7190)) : Αυτή είναι μια άλλη αναφορά μπλοκ.
- 3. Υποστηρίζετε ετικέτες;
    - Φυσικά, αυτή είναι μια #δοκιμαστική ετικέτα.
- 4. Υποστηρίζετε εργασίες όπως todo/doing/done και προτεραιότητες;
    - Ναι, πληκτρολογήστε `/` και επιλέξτε τη λέξη-κλειδί εργασίας ή προτεραιότητα (A/B/C) που προτιμάτε.
    - NOW [#A] Ένα δοκιμαστικό εκπαιδευτικό υλικό σχετικά με "Πώς να κρατάτε δοκιμαστικές σημειώσεις;"
    - LATER [#A] Δείτε αυτό το εξαιρετικό βίντεο από [:a {:href "https://twitter.com/shuomi3" :target "_blank"} "@shuomi3"] σχετικά με τη χρήση του Logseq για σημειώσεις και οργάνωση της ζωής σας!
    {{youtube https://www.youtube.com/watch?v=BhHfF0P9A80&ab_channel=ShuOmi}}

    - DONE Δημιουργία σελίδας
    - CANCELED [#C] Συγγραφή σελίδας με περισσότερα από 1000 μπλοκ
